## Project Overview

SUS2211 — "Mapeando la (In)sustentabilidad" is a Quarto-based course website for Pontificia Universidad Católica de Chile. It produces two types of output: Reveal.js lecture slides (`clases/`) and HTML homework documents (`homeworks/`). All content is in Spanish.

## Build Commands

The project has two separate Quarto sub-projects that must be rendered independently:

```bash
# Render lecture slides
cd clases && quarto render

# Render homework documents
cd homeworks && quarto render

# Render a single file
quarto render clases/lectures/clase01.qmd
quarto render homeworks/tarea02.qmd

# Preview with live reload
quarto preview clases/lectures/clase01.qmd
quarto preview homeworks/tarea02.qmd
```

There is no top-level `_quarto.yml` — you must render from within `clases/` or `homeworks/`, or specify the file path directly.

## Architecture

- **`clases/`** — Lecture sub-project. Renders Reveal.js slides to `docs/`.
  - `lectures/*.qmd` — Slide decks
  - `figures/clase*/` — Per-lecture images
  - `templates/` — Reusable slide fragment templates (section, activity, map, etc.)
  - `theme.scss` — Shared Reveal.js theme
  - `inputs/` — Source materials (gitignored)

- **`homeworks/`** — Homework sub-project. Renders HTML documents to `docs/homeworks/`.
  - `tarea*.qmd` — Step-by-step assignment instructions with embedded screenshots
  - `figures/tarea*/` — Per-assignment screenshots
  - `templates/documento.scss` — Document theme
  - `inputs/` — Data files (gitignored)

- **`docs/`** — Generated static site output (committed to repo, likely served via GitHub Pages).
  - `index.html` — Hand-crafted landing page (not generated by Quarto)

- **`homeworks_zips/`** — Packaged .zip downloads for students containing data and project templates.

## Key Details

- Quarto version: 1.9.30
- Output is self-contained (`embed-resources: true`) — each HTML file includes all assets inline.
- The `inputs/` directories are gitignored (contain large datasets, proprietary .pptx/.pdf files).
- The `docs/` directory is committed and should be updated after rendering.
- Homework assignments reference a standardized student folder structure: `datos/brutos/`, `datos/intermedios/`, `datos/procesados/`, `proyectos/`, `resultados/`.
